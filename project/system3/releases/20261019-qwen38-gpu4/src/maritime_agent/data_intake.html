首次接入建议上传 GIS 边界。系统会用首个来源的空间范围建立临时边界，后续来源必须与其相交。

仅在文件确实表示研究区边界时勾选；普通航道、港口点或设施图层不要勾选。

可一次选择多个同类型、同研究区域的文件，系统逐文件预览校验后批量确认入库。AIS 还支持含多份表格的 ZIP；未知列按原名保存在扩展属性中。系统保存每个来源的文件指纹、质量报告和修复审计。
