# 导师汇报：方法与完整实验结果

## 第 1 页：研究主线：让轨迹判断有可靠的群体参照

面对位置跳变、船群共同变化与目标机动混在一起的情况，研究目标是为不同轨迹模型构造可比较的局部参考。

核心思路：先根据位置变化与报告速度是否一致估计观测可信度；再排除目标船，用附近同向船舶估计背景速度；最后比较目标与群体的运动变化，并接入不同轨迹模型。

**研究任务与输出**

| 任务 | 回答的问题 | 评价依据 |
| --- | --- | --- |
| 个体机动识别 | 目标自身是否发生预设机动 | 受控机动标签与 AP |
| 群体关系识别 | 目标变化是否与周围群体一致 | 四格组合标签与 AP |
| 短时航迹预测 | 根据已见轨迹预测后续位置 | 后续 AIS 观测与距离误差 |

注：三项实验共用可信度与背景场思想，但输出和评价依据不同。

主要结论：目标门控对受控观测污染有保护作用；可信背景在部分邻船污染条件下改善关系识别；不同骨干和污染方式的收益不完全相同。

## 第 2 页：方法一：先判断报文是否相容

AIS 报文同时包含位置、航速和航向，可以用两种速度的差异判断这一时刻的观测是否一致。

**从观测到可信度**

| 步骤 | 具体含义 |
| --- | --- |
| 位置差分速度 | 相邻位置差 ÷ 相隔时间，得到位置体现出的速度 |
| 报告速度 | 根据报文航速和航向，换算东西、南北速度 |
| 相容残差 e | 两种速度向量之差的长度；差异大，说明报文存在不一致 |
| 可信度 w | w = exp(-max(0, e - 2.5)^2 / 8)，数值越低，下调影响越强 |
| 因果门控 | 结合此前可信运动信息处理可疑步，不使用未来报文 |

注：速度以米/秒计算；可信度反映观测相容程度，不是人工标注的异常概率。

位置修正按步间变化处理。预测实验额外使用重锚定：当前观测恢复可信后，重新使用当前可见位置，减少过去修正误差的累积。

## 第 3 页：方法二：留一背景场与动态范围

目标船可能只是跟随周围船群一起减速，因此需要先估计目标附近船群的共同运动。

**背景场的组成**

| 名称 | 容易理解的解释 |
| --- | --- |
| 留一法 | 计算背景时排除目标船，避免自己参与定义自己的参照 |
| 普通背景场 | 用距离对合格邻船加权，估计局部背景速度 |
| 可信背景场 | 同时考虑距离和观测可信度，降低可疑邻船影响 |
| 个体残差 | 目标速度减背景速度，反映目标相对船群的运动差异 |
| 散度与旋度 | 描述局部背景速度的聚散变化和旋转趋势 |
| 动态半径与回退 | 依次尝试3.5、5、8海里；不足6船时可使用简单加权平均 |

注：原八骨干实验和后续动态半径实验是不同版本；六船门槛用于后者。

训练阶段可增加受背景状态控制的扰动和一致性约束；关系任务采用分类训练。模型比较均保留相应的基础模型。

## 第 5 页：标签和指标：每个数字到底代表什么

预测任务和检测任务回答不同的问题，不能把它们的指标相互替代。

**评价依据与指标**

| 名称 | 含义及阅读方法 |
| --- | --- |
| 受控机动标签 | 按指定规则构造转向、减速等机动；普通机动不自动等于真实异常 |
| 四格关系标签 | 目标与群体均变化或均不变为一致；只有一方变化为不一致 |
| AP | 按模型分数排序，综合衡量目标样本排在前面的能力；越高越好 |
| AUROC | 正负样本排序区分能力；50%约为随机排序 |
| 误报率 FAR | 负样本中被判成目标的比例；越低越好 |
| 召回率 Recall | 目标样本中被检出的比例；越高越好 |
| ADE / FDE | 预测轨迹平均位置误差 / 末点位置误差；单位米，越低越好 |
| F1 分数 | 综合精确率与召回率；依赖所选判断阈值 |
| P90 | 误差从小到大排序后，约90%样本不超过的值 |
| 95%配对区间 | 同一批目标船上两种方法的差值范围；跨零表示方向不明确 |

注：预测参考是未来 AIS 观测，不是无误差的物理真值；检测使用人工生成的受控标签。两个百分比相减用百分点表示。

## 第 24 页：现阶段结论与写作重点

实验已经形成从观测可信度、群体参照到不同下游任务的完整证据链。

**可以直接用于论文的结论**

| 实验 | 结果说明 |
| --- | --- |
| 个体机动 | 八骨干完整配置平均 AP 均高于基础配置；各模块作用需配对判断 |
| 群体关系 | 自然速度污染下，可信背景在多个骨干上改善识别 |
| 短时预测 | 目标观测跳变或速度尖峰时，重锚门控明显降低误差 |
| 动态邻域 | 回退增加有效参考覆盖率；港口自然速度污染下可信场改善表现 |
| 近期方法 | 多数方法接入后提升，CARLA 在该配置下降 |

注：结果使用不同实验版本；逐表核对任务、模型、数据划分、训练条件和指标口径。

写作时应明确：预测使用后续 AIS 观测作为参考；机动与关系任务使用受控标签。既有测试来源曾参与开发，低密度关系组规模较小。
