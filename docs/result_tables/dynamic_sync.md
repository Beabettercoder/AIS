# 关系任务：扩圈邻船同步机动与六船仿射门槛

## 结果概览
1. 测试集基础观测下，固定小半径、固定大半径、动态普通场＋回退、动态可信场＋回退的有参考覆盖率依次为 64.73%、92.35%、97.22%、97.02%。受限水道依次为 22.16%、73.93%、88.34%、88.04%；覆盖率包含零阶回退。
2. 自然时间速度污染下，动态可信场相对动态普通场的 AP：TCN +5.02 个百分点 [2.30, 7.63]，GRU +6.37 [3.24, 9.41]，Transformer +3.34 [−0.15, 6.77]，GAT-TCN +5.37 [2.61, 8.21]。其中 Transformer 区间跨零，其余三个区间大于零。
3. 在后段速度及速度＋位置复合污染下，四骨干的可信场与动态普通场 AP 差异区间均跨零；基础观测下 Transformer 的可信场低 1.78 个百分点 [−3.51, −0.10]。
4. 自然速度污染下，在三组都有参考且污染命中的共同时间步，背景速度平均变化由 0.673 降至 0.262 米/秒；后段速度污染为 0.381 降至 0.317 米/秒；复合污染为 0.307 与 0.325 米/秒，配对差值区间跨零。
5. 与上一版扩圈实验相比，同一批基础测试样本的动态可信场 AP 提高 3.99～5.52 个百分点。同步群体机动与六船门槛同时改变，不能将这一差值单独归因于某一项。原四格干预是受控生成，该结果并不代表真实航海事件识别率。

本实验保留原有 2,034 / 272 / 220 个训练、验证、测试来源及目标船身份划分。在每个四格样本中，让扩圈后可能入选的同向邻船与原指定船群同步执行平滑减速：300 秒内最多减速 30%，同时积分修正位置。位置和速度的原有相容残差由构造保持。

污染对象按来源和船舶身份的确定性哈希选择，概率约 50%，与四格标签无关。自然时序和后段时序分别施加连续两条报文的 3–5 倍速度干扰；复合视图同时施加 600 米位置偏移。实际选中率和命中率见下表。

四个骨干、三种子，每个场配置 25 轮；以第 25 轮为主要对照，验证集最优权重结果另存。所有一阶场至少需要 6 艘邻船且通过几何条件检查；允许回退的配置在船数不足时使用零阶加权均值。普通场只用距离加权；可信场还使用运动学筛选和加权。GAT-TCN 使用目标船与背景摘要两个节点的分类适配实现。

原四格来源的入选仍依赖原有可信邻船条件，测试集此前使用过。同步减速是受控构造，不意味着真实船舶发生同样机动。低密度组与地理分组重叠，不等同开放海域；邻船背景可能跨集合复用。
