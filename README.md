# 可信度感知的多主体轨迹建模：科研代码快照

本仓库整理 AIS 轨迹研究的服务器源码，包括运动学相容门控、留一局部背景场、单主体机动与群体关系检测、轨迹预测、动态邻域半径研究，以及 `system3` 的源码快照。

## 目录

- `project/ais_ad/`、`project/scripts/`：原始数据处理、模型与历史实验脚本。
- `project/outputs/formal_20261101/`：八类骨干的单主体与群体关系实验脚本。
- `project/forecast_reanchor_run_20261106/`：轨迹预测与重锚门控实验脚本。
- `project/published_detectors_20261106/`：近期方法的实验接入与桥接脚本。
- `experiments/adaptive_radius_v2p1/`、`adaptive_radius_v3/`、`adaptive_radius_sync_v4/`：动态半径、可信场和群体同步干预实验代码。
- `project/system3/`：服务器上的系统代码快照，保留相对层级；其中可能含历史版本，不代表当前部署状态。
- `docs/`：中文方法与实验结果报告及其可编辑文本。
- `SOURCE_MANIFEST.json`：源文件相对路径、字节数与 SHA-256，用于追溯本次打包内容。

## 数据与运行

本仓库不包含原始 AIS 报文、数据库、逐船记录、模型权重、训练日志、虚拟环境及密钥。部分旧脚本使用原服务器绝对路径，并依赖既有预处理数据与实验配置；下载仓库后**不能直接复现全部实验**。运行前需根据本机环境修改路径，重新准备合法可用的数据和 Python 依赖，再核对对应实验协议与训练种子。

近期方法的第三方上游仓库和环境文件未打包；对应适配脚本保留在仓库中。请根据各方法的官方项目、许可证和依赖自行获取上游代码，不能把这里的适配实现等同于作者官方完整复现。

报告中的受控机动与四格关系标签属于实验构造。不同版本的数据、训练和邻域策略不同；已用于开发的测试集不是新的盲测集。请按报告中的表注和实验版本解读。

## 安全与授权

本快照排除了常见密钥文件和缓存，并对两个测试文件中的疑似密钥字面量作了替换。`SOURCE_MANIFEST.json` 记录替换位置。历史案例核验脚本的无效删除语句已在发布副本修复，服务器原件未修改；具体路径和原始哈希记录在清单中。源码中的路径和示例需要在实际使用前审查；如部署到真实系统，请自行配置凭据并确保数据使用权限。
